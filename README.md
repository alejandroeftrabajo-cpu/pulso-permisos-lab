# PULSO Permisos · v6.3 editorial y cromática

Laboratorio de demostración con datos ficticios. No conectado a Google Sheets, Séneca ni Apps Script.

## Cambios
- Azul petróleo, coral y granate institucional.
- Mejor contraste de tipografía secundaria y jerarquía visual.
- Calendarios, navegación, métricas, estados, formularios y expedientes armonizados.
- Textos de saldo y compromisos revisados para evitar confundir concesión y solicitud.
- Control de caché con versión 6.3 en los recursos.

## Alcance
Se conservan las funciones JavaScript de v6.2. La simulación no emite resoluciones.
La normativa, el calendario y las reglas de desempate siguen pendientes de validación.

## Publicación
Subir index.html, styles.css, app.js y logo.jpg a GitHub Pages conservando los nombres.
