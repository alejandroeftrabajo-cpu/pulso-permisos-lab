# PULSO Permisos v6.6 · Analítica y memoria

Laboratorio GitHub Pages. Datos exclusivamente ficticios.

## Funcionalidades
- Filtro por curso o trimestre.
- KPIs, distribución mensual y por día de la semana.
- Fechas de mayor concurrencia con acceso al expediente.
- Proximidad a días no lectivos (calendario parcial del laboratorio).
- Resumen de estados y ausencia explícita de motivos y criterios cuando no hay datos.
- Informe redactado de demostración, con impresión/Guardar como PDF desde Safari.

## Limitaciones
No conectado a Sheets ni Apps Script. No resuelve permisos. No registra criterios normativos,
motivos de denegación ni disfrute efectivo. No genera un PDF oficial en servidor.
El informe PDF se obtiene mediante el diálogo de impresión del navegador.
